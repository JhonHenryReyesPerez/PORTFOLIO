Sobre mí

Me interesa construir soluciones bien estructuradas y entender la lógica detrás de cada implementación.

Soy desarrollador de software en formación, con enfoque en el backend con Java y Spring Boot. Tengo experiencia académica y práctica construyendo aplicaciones web, APIs REST, bases de datos relacionales e integraciones con herramientas de automatización.

Hoy sigo fortaleciendo mis conocimientos en arquitectura de software y buenas prácticas de desarrollo.

Lo que he trabajado hasta ahora

  • APIs REST con Spring Boot, organizadas por capas o con MVC.
  • Seguridad con Spring Security, autenticación JWT y control de acceso por roles.
  • Bases de datos relacionales en PostgreSQL y MySQL: modelado, más de 20 triggers y eventos programados.
  • Interfaces web con HTML, CSS y JavaScript, desde una tienda de música responsive hasta el seguimiento de obras de construcción.
  • Mapas interactivos con Leaflet.js e integración de APIs externas.
  • Automatización de procesos con n8n y servicios en contenedores con Docker.
  • Hackathons como SmartCity Fix y NeoMetro, llevando una idea a una plataforma funcional.
  • Fundamentos de programación con Python: ejercicios y estructuras fundamentales.
